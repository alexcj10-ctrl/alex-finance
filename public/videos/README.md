# Video delle lezioni

Questa cartella ospita i file MP4 esportati da FM Stadio.

Per pubblicare un video:

1. copia qui il file `.mp4`;
2. usa un nome semplice in minuscolo, senza spazi;
3. inserisci il percorso `/videos/nome-file.mp4` nel catalogo `src/data/lessons.ts`;
4. se hai anche i sottotitoli italiani, copia il file `.vtt` e aggiungi il campo opzionale `percorsoSottotitoli`;
5. imposta lo stato della lezione su `disponibile`.

Il solo file MP4 è sufficiente: l'assenza del file VTT non impedisce la riproduzione del video.
